## Run
```bash
npm install
npm run dev
```

## Stack
Next.js App Router, TypeScript, Tailwind v4, shadcn-compatible `/components/ui`, Motion, lucide-react.

Predominantly white. Grid/mesh only inside contained panels. Gradient is a light accent. Avoid generic AI imagery and card overload. Mobile quality is first-class.
